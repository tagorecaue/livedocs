## Por que existe esta página

Este projeto é mantido por um brasileiro, em um repositório open
source, mas a documentação principal (incluindo a própria skill) é
em inglês — porque é o idioma que os agentes de código usam como
padrão e o público de desenvolvedores é global.

A skill em si **gera documentação em qualquer idioma** (configurado
na Fase 0 do bootstrap). Então mesmo lendo o manual em inglês, você
pode rodar a skill no seu projeto e ela produz `.md` e `.tech.md`
em pt-BR sem nenhum ajuste.
